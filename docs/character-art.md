# Artwork credits

Sonvane uses the original paired-S vector mark and a consistent set of creator illustrations. The creator is fictional. The blue companion represents the planning assistant; it is not an official Meta or Muse mascot. TuneJury retains its existing character identity.

| Asset | Role |
| --- | --- |
| `situation-brief-v1.png` | Planning sound around a video |
| `situation-clarify-v1.png` | Discussing musical intent |
| `situation-criteria-v2.png` | Reviewing timing and direction |
| `situation-compare-v2.png` | Comparing generated music with TuneJury |
| `situation-record-v1.png` | Keeping the selected mix and its record |

The illustrations were created with an image-generation tool using creator-supplied visual references, then selected and reviewed by Yonghyun Kim. They appear in Overview, Studio, the README and the technical report. Drawn laptop interfaces are illustrative, not screenshots or proof of implemented controls.

The selected original artwork is preserved. TuneJury has a closed-mouth curved smile, white short sleeves, exposed charcoal arms, a rounded monitor head and the established pencil texture. See [third-party notices](THIRD_PARTY.md) for model, font and software credits.
