# Sonvane

A sound director for your video. Review Muse's plan, create music with ACE-Step, compare with TuneJury, and keep your chosen mix.

This Space connects to a separate GPU service. Model API credentials remain on that service; connection credentials are stored in Space Secrets. Uploaded videos and saved preferences use an isolated demo workspace.

[Source and technical report](https://github.com/yonghyunk1m/sonvane)
